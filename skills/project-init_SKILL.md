# 项目初始化工作流

## 执行条件
在本项目（D:\桌面\工作流模板）做任何实质性工作之前，**必须先执行本 skill**。

## 工作流

### Step 1: 读取项目规范
读取 `D:\桌面\工作流模板\提示词.md`，这是本项目的核心规范文件，包含：
- 工作风格与行为约束
- P0/P1 核心纪律
- Skill 索引表（何时调用哪个 skill）

### Step 2: 读取模板文件
读取 `D:\桌面\工作流模板\模板库\案件概览模板.md`，这是物理模板文件。**新建案件时必须以此模板为蓝本**，仅替换：
- `{案件名}` 和 `{年度}` 占位符
- frontmatter 中的空字段（案号、案由、法院等）

### Step 3: 环境检查
读取 `D:\桌面\工作流模板\SETUP.md`，逐项检测：
- Python 环境（3.8+）
- markitdown 是否已安装
- 如任一缺失 → 暂停，输出安装指令，等待用户确认后再继续

### Step 4: 确认理解
读完后确认理解以下关键点：
- 案件概览文件的标准 YAML 格式（tags/case、律师: 强晖、结果用列表、下个任务）
- 关联文档格式：fold 折叠 + 分4类 dataview
- .base 文件的正确语法（用 `order` 不用 `properties`，用 `file.basename.containsAny` 筛选）
- 文件夹结构标准（01_材料原件/ → ... → 07_诉讼文书/）

### Step 5: 开始工作
只有在完成 Step 1-4 后，才能开始用户的任务。

## 违规后果
不读提示词和模板就动手 = 必犯错。之前因为没读正确格式，.base 文件重写了5次，案件概览格式也不统一。
