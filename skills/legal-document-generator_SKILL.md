# Legal Document Generator — 法律文书生成器

> 本 skill 负责法律文书的**内容生成**与**格式规范**，与 `litigation-analyst`（案件流程管理）互补协作。

---

## 一、定位与边界

| | litigation-analyst | legal-document-generator |
|---|---|---|
| **职责** | 案件材料管理与归档 | 文书内容生成 + 格式规范 |
| **调用时机** | 案件收料、建档、归档 | 需要起草/生成法律文书时 |
| **输出** | 案件档案、材料清单 | 合同、起诉状、答辩状、律师函等终稿 |

**协作方式：** 文书生成时可从 litigation-analyst 管理的案件文件夹中读取当事人信息、事实材料作为输入。

---

## 二、核心能力

### 2.1 合同类文书

- 销售合同、服务协议、租赁合同、借款合同
- 劳动合同、合伙协议、保密协议

**结构要求：** 标题+编号+日期 → 甲乙方信息 → 条款正文（第一条…） → 签署栏

### 2.2 民事诉讼文书

- 民事起诉状、民事答辩状、反诉状
- 财产保全申请书、证据清单

**格式标准：**
- A4 幅面，宋体正文 / 黑体标题
- 标题 22pt → 一级标题 18pt → 正文 12pt
- 行距 1.5 倍，页边距 上3cm 下2.5cm 左3cm 右2.5cm

**必备要素：** 当事人信息 → 受案法院 → 诉讼请求 → 事实与理由 → 法条依据 → 签名日期

### 2.3 刑事辩护文书

- 辩护意见书、刑事辩护词
- 取保候审申请书、从轻处罚申请书

### 2.4 法律意见与合规

- 法律意见书、尽职调查报告
- 合规意见、风险评估报告

**结构：** 执行摘要 → 事实背景 → 法律分析 → 风险评估 → 建议

### 2.5 行政与催收文书

- 行政复议申请书、行政诉讼文书
- 律师函、催款函、警告函、停止侵权函

## 三、文书生成工作流

```
① 明确需求 → 识别文书类型，收集当事人/事实/法条
    ↓
② 结构搭建 → 按该类文书标准格式组织框架
    ↓
③ 内容起草 → 使用精确法律术语，引用具体法条
    ↓
④ 审查校验 → 检查要素完整性、法条准确性、格式规范性
    ↓
⑤ 输出交付 → Markdown 编辑版 或 .docx 终稿
```

## 五、本地化适配规则

1. **默认中文输出** — 所有文书以简体中文生成
2. **法条来源优先级**：法律法规库本地文件 > 本 skill 参考库 > 公开检索
3. **格式优先 Markdown** — 除非用户明确要求 .docx，否则先出 md
4. **与 litigation-analyst 协作时**：遵循后者的案件文件夹结构和命名规范
5. **模板为起点而非终点** — 根据具体案情调整，不机械套用

---

## 六、文件命名规范

```
{文件名称}_{备注版本}_{编辑日期}.md
```

示例：`起诉状_v1_20260423.md`、`证据目录_原告_20260420.md`

---

## 七、.doc 文件处理

遇到 `.doc` 格式须先转为 `.docx` 再提取内容：
- 首选 MS Word（`SaveAs2(FileFormat=16)`）
- 备选 LibreOffice
- 禁止直接重命名或用 olefile/antiword 等低质量方案

---

## 八、法律法规引用规范

- 第一优先从本地 `法律法规库/` 引用，注明文件名及条文编号
- 本地库没有的法条：立即暂停，向用户提示，**严禁**以训练数据替代或自行填充
- 未经用户明确指令，不得对现有法律法规文件进行增删改
- 新增法律文件按 `{法律名称}_{版本标记}_{日期}.md` 命名，存入对应子文件夹
