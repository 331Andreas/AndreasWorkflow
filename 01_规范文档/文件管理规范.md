# 文件管理规范

> 本文件定义诉讼案件数据库中文件接收、归档、命名的详细操作规则。

---

## 一、文件命名规则

所有输出文件统一使用以下命名格式：

```
{文件名称}_{备注版本}_{编辑日期}.md
```

示例：
- `起诉状_强晖v1_20260423.md`
- `代理意见_最终版_20260425.md`
- `证据目录_原告_20260420.md`

---

## 二、收料规则

### 2.1 材料接收

1. 新接收的原始材料统一放入 `收料库/` 文件夹
2. 按批次分子文件夹：`收料库/{日期}_{简要描述}/`
3. 原始文件保持原格式不动，不做任何修改

### 2.2 OCR 处理

1. 对扫描件/图片类文件执行 OCR
2. 处理后生成可读版本，存入案件对应目录
3. 原件保留在收料库，处理版存入 `案件库/{案件名}_YYYY/01_材料原件/`

---

## 三、归档规则

### 3.1 案件文件夹标准结构

```
案件库/{案件名}_{年度}/
├── {案件名}_案件概览.md
├── 01_材料原件/
├── 02_材料清单.md
├── 03_案件信息.md
├── 04_法条检索/
├── 05_案例检索/
├── 06_检索报告/
├── 07_诉讼文书/
├── 08_庭审材料/
└── 09_结案材料/
```

### 3.2 文书归档映射

| 文书类型 | 归档目录 |
|----------|---------|
| 起诉状 / 答辩状 / 上诉状 | `07_诉讼文书/` |
| 传票 / 开庭通知 | `08_庭审材料/` |
| 判决书 / 裁定书 / 调解书 | `07_诉讼文书/` |
| 受理通知书 / 缴费通知 | `07_诉讼文书/` |
| 证据材料 | `01_材料原件/` |

### 3.3 文书重命名规则

```
{标题}_{案件简称}_{YYYYMMDD}收.pdf
```

## 四、法律法规库管理

### 4.1 存储结构

```
法律法规库/
├── 民法典/
├── 民事诉讼法/
├── 刑法/
├── 行政法/
├── 公司法/
├── 劳动法/
└── ...
```

### 4.2 命名规则

```
{法律名称}_{版本标记}_{日期}.md
```

### 4.3 更新纪律

- 未经明确指令，禁止对现有文件进行任何删改
- 新增文件按命名规则存入对应子文件夹
