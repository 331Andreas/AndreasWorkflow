## 事实与理由

### 一、劳动关系的建立与竞业限制约定

2020年6月1日，原告与被告签订《劳动合同》（编号：JC-HR-2020-0601），约定被告担任技术总监一职，年薪人民币80万元+期权，合同期限为2020年6月1日至2023年12月31日。

《劳动合同》第五条约定了被告的保密义务，明确被告在职期间及离职后对原告的商业秘密（包括但不限于技术方案、源代码、算法模型、客户信息等）负有严格保密义务。第六条约定了竞业限制义务：被告在劳动合同解除或终止后24个月内不得从事与原告存在竞争关系的业务，竞业限制补偿金标准为每月人民币25,000元，违反竞业限制义务的违约金为人民币100万元。

劳动合同签订后，被告作为技术总监，全面负责原告核心技术产品的研发工作，深度参与了原告核心产品——**"锦程大数据智能分析系统V3.0"**（软著登记号：2022SRXXXXXXX）的技术架构设计、核心算法研发及源代码编写，掌握了原告全部核心商业秘密。

### 二、离职协议的签订与竞业限制义务的确认

2023年12月31日，被告因个人发展原因申请离职。当日，双方签署《离职协议》（编号：JC-HR-LZ-2023-1231），就劳动合同解除及后续事宜进行了全面约定。《离职协议》第二条再次确认了被告的竞业限制义务：

- 竞业限制期限：2024年1月1日至2025年12月31日（24个月）；
- 竞业限制补偿金：每月人民币25,000元，于每月15日前支付；
- 违约金：人民币100万元，且违约方应退还已收取的全部竞业限制补偿金；
- 被告应在每月5日前以电子邮件形式向原告报告其就业状况。

《离职协议》第三条确认了被告的保密义务永久有效，被告承诺已于2023年12月31日前将全部含有原告商业秘密的文件、资料完整归还原告，未以任何形式私自留存、复制或转发。

### 三、原告全面履行了竞业限制补偿金支付义务

自2024年1月15日起至2024年12月15日止，原告按月通过招商银行对公账户向被告本人招商银行账户（账号：6214********5678，与《离职协议》第2.4条约定一致）支付竞业限制补偿金，共计12期，合计人民币 **300,000元**。每笔支付均有银行转账记录为证。

### 四、被告违反竞业限制义务的事实

**（一）入职竞对公司**

经原告核实，被告在竞业限制期内的2024年3月15日，入职了**星辰数据（北京）科技有限公司**（统一社会信用代码：91110108MA00XYZ999），担任首席技术官（CTO）。

星辰数据于2024年2月18日在北京市海淀区注册成立，经营范围包括：大数据分析平台的技术开发与服务、人工智能算法研发与应用、数据处理、软件开发等。该经营范围与原告的营业执照登记经营范围及实际经营业务高度重合，**构成直接竞争关系**。

被告不仅入职竞对公司，且以星辰数据CTO身份公开参与行业活动。2024年7月15日，被告以星辰数据CTO身份在"北京大数据产业峰会"上发表主题演讲，其公开资料中明确显示其职务为"星辰数据 首席技术官"。被告入职竞对公司的行为，**仅距离职日2.5个月**，主观违约故意极为明显。

**（二）竞对公司产品与原告高度相似——涉嫌泄露商业秘密**

2024年6月20日，星辰数据在"2024北京国际大数据博览会"上首次发布了**"星图数据智能分析平台V1.0"**。原告经内部技术比对发现，该产品在以下方面与原告的"锦程大数据智能分析系统V3.0"存在高度相似：

| 对比维度 | 锦程科技V3.0 | 星辰数据V1.0 | 相似度 |
|----------|-------------|-------------|--------|
| 技术架构 | Spring Cloud + Flink + Elasticsearch | Spring Cloud + Flink + Elasticsearch | 一致 |
| 数据接入框架 | 自研"JC-Connector"多源适配框架 | 自研"Star-Link"多源连接器 | 架构高度相似 |
| 数据处理引擎 | 基于DAG的流式处理管线 | 基于DAG的数据处理管线 | 一致 |
| 智能预警模型 | 基于LSTM+Attention专利技术 | 基于深度学习的异常检测 | 参数高度相似 |
| API接口设计 | 特殊Token鉴权格式 | Token格式与原告一致 | 完全一致 |
| 用户界面布局 | 蓝色主题三栏式布局 | 深蓝色三栏式布局 | 高度相似 |

上述多处"高度相似"已超出行业通用技术的合理范畴，结合被告曾在原告处担任技术总监并全面掌握核心源代码的事实，**有充分理由认定被告违反保密义务，将原告的商业秘密泄露并用于竞对公司产品研发**。

### 五、原告的维权过程

2025年1月10日，在完成初步证据收集后，原告依据《离职协议》第2.5条停止向被告支付后续竞业限制补偿金。

2025年3月1日，原告委托律师向被告发出《律师函》，要求被告：（1）立即停止违反竞业限制义务的行为；（2）从星辰数据离职；（3）停止使用原告商业秘密；（4）协商赔偿事宜。该律师函于2025年3月2日通过EMS快递送达并由被告本人签收。

然而，被告在收到律师函后未作任何回应，既未停止违约行为，也未与原告进行任何沟通协商，充分表明其漠视合同义务和法律约束的主观态度，存在明显恶意。

### 六、被告应承担的违约责任及侵权赔偿责任

1. **竞业限制违约金100万元**：被告的行为完全构成对竞业限制义务的违反，原告有权依据《劳动合同法》第二十三条、《劳动合同》第六条及《离职协议》第二条之约定，要求被告全额支付违约金人民币100万元。

2. **退还原告已支付的补偿金30万元**：依据《离职协议》第2.5条，被告在违反竞业限制义务的情况下，应退还原告已支付的全部竞业限制补偿金共计30万元。

3. **赔偿商业秘密侵权损失200万元**：被告违反保密义务，将原告商业秘密泄露并用于竞对公司产品研发的行为，已构成对原告商业秘密的侵犯，依据《反不正当竞争法》第九条、第十七条及《劳动合同法》第九十条之规定，应承担侵权损害赔偿责任。原告因被告的侵权行为遭受的经济损失初步核算约为200万元（含研发投入贬值、竞争优势丧失、潜在客户流失等）。

4. **律师费及全部诉讼费用**：依据《反不正当竞争法》第十七条第三款之规定，原告为制止侵权行为所支付的合理开支应由被告承担。
