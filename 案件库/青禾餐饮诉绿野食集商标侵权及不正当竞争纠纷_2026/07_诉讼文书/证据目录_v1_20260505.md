## 证据分组与证明逻辑

### 第一组：权利基础证据（证据1、证据7）

```
证据1（商标注册证）+ 证据7（原告主体资格）
        ↓
证明原告系适格诉讼主体，对"青禾小馆"享有注册商标专用权
```

### 第二组：侵权事实证据（证据2、证据8）

```
证据2（公证书：门店对比照片）+ 证据8（被告工商信息）
        ↓
证明被告在杭州经营"青禾轻食"门店，全面模仿原告品牌装潢
```

### 第三组：知名度及"有一定影响"证据（证据3、证据9）

```
证据3（品牌经营数据）+ 证据9（装修合同）
        ↓
证明原告品牌在侵权行为发生时已具备较高知名度和"有一定影响的商品装潢"
```

### 第四组：主观恶意证据（证据4、证据5、证据6）

```
证据4（律师函）→ 证据5（送达回执）→ 证据6（被告拒绝回复）
        ↓
证明原告已履行善意催告义务→被告已知侵权事实→被告明确拒绝并持续侵权
        ↓
被告主观恶意明显，系"明知故犯"
```
